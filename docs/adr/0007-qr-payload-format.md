# ADR-0007: QR payload format

- Status: Accepted
- Date: 2026-09-27

## Context

Job travelers (PT-025) carry QR codes scanned by the shop-floor PWA.

## Decision

As specified in docs/02 section 9. Implementation is deferred to Sprint 3 (PT-025/PT-028); this ADR records the decision only.

## Consequences

+ Format fixed before printing starts.

## Alternatives considered

Barcodes (Code 128).
